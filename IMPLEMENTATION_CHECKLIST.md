## User Workflow

### Step 1: Launch Report
```
User clicks "Insights" button on location card
↓
Modal opens and starts loading data
↓
Data fetches from Google Business Profile API
```

### Step 2: Auto-Save
```
Data received by PerformanceInsightsModal
↓
useEffect triggers auto-save to MongoDB
↓
"✓ Saved to Database" indicator appears
↓
User sees beautiful report with charts
```

### Step 3: Optional Date Range Change
```
User clicks "Change Date Range"
↓
Date picker appears
↓
User selects new dates and clicks "Apply"
↓
onDateChange handler triggers refresh
↓
Report updates with new data range
```

### Step 4: Download PDF
```
User clicks "Download PDF"
↓
PDF generation starts
↓
Beautiful professional report generated from component
↓
PDF automatically downloads with proper filename
↓
Footer shows "Generated by Limbu AI"
```

## API Endpoints

### Save Insights
```
POST /api/performance-insights
Headers: Content-Type: application/json
Body: {
  locationId, businessName, locationName, businessProfileId,
  insightsData, searchKeywords, metrics, dateRange, reportMonth, reportYear
}
Response: { success: true, data: savedInsight }
```

### Fetch Insights
```
GET /api/performance-insights?locationId=xxx&reportMonth=xxx&reportYear=xxx
Response: { success: true, data: [insights...] }
```
